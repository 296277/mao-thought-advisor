# 《毛选》精读协议

## 目标

精读不是把每段换一种说法，而是重建文本在特定历史情境中的问题、论证和行动含义。输出应让读者能回到原文核对，也能看见后续历史结果与当代迁移的边界。

## A. 语料登记

为每个文件登记：文件名、来源/授权说明（若用户愿意提供）、版本/出版社、出版年份、卷次、扫描或文本质量、页码是否连续、OCR 疑似错误。不得自行填补未知字段。

建议清单格式：

```text
文件：
卷次：
版本：
覆盖篇目：
页码/文件页：
质量问题：
状态：未读 / 精读中 / 已精读 / 待核
```

## B. 分段与定位

优先按原书标题、自然段、脚注和编者说明分段；不要只按固定字数切块。每个笔记单元保留起止页码或文件页码。OCR 文本须保留原始文件，修订字词需记录“原 OCR—校正—依据”。

## C. 单篇精读卡

```text
卷 / 篇：
写作时间与历史场景：
文本对象与现实问题：
中心论题（一句话）：
段落结构：
论证链：
核心概念：
关键事实 / 例证：
作者回应的反对意见：
隐含前提：
适用条件与失效条件：
与其他篇目的关系：
历史后果与后见之明：
现代非暴力迁移：
仍需核验的问题：
原文定位：
```

## D. 跨篇综合

每完成一篇，更新四张表：

1. **概念表**：概念、定义、出现篇目、语境变化、相近/相反概念；
2. **问题表**：作者反复处理的问题、不同阶段的答案、答案变化原因；
3. **方法表**：方法、前提、适用阶段、可观察指标、现代迁移边界；
4. **争议表**：版本差异、史实争议、后续实践、学界不同解释。

跨卷比较时优先问：

- 同一概念在战争、建设、治理语境中是否改变含义？
- 哪些判断是阶段性策略，哪些被表述为原则？
- 后文是重复、发展还是修正前文？
- 哪些结论依赖特定组织结构、资源条件或政治目标，不能直接类比当代个人生活？

## E. 证据等级

- **A：** 用户提供的可定位原文或可靠版本的明确信息；
- **B：** 多篇原文相互印证的解释；
- **C：** 基于文本和历史背景的合理推断；
- **D：** 当代类比或实践建议。 

回答中要显式区分等级。遇到篇名、日期、页码、原句无法确认时，降级并标 `[待核]`，不以流行摘录替代原文。

## F. 交付节奏

不要承诺一次性“读完并永久记住”。建议按卷或 3—8 篇为一批：

1. 先交付阅读清单与版本问题；
2. 再交付单篇精读卡；
3. 然后交付跨篇主题综合；
4. 最后用用户指定问题做盲测式回溯，检查是否能准确回到原文定位。

若用户要求长篇逐字复现，优先提供定位、短引和分析；长段原文只处理用户明确提供且有权使用的内容。
